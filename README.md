# The One-Liner Groan-Off

![competition](https://make.fun/badge/u-alfasurya91-the-one-liner-groan-off-5a1febd5.svg)
![rank](https://make.fun/badge/ovokai/one-liner-groan-off/rank.svg)

One original dad joke, delivered by a tiny program. Run it and it writes the
joke to `/output/entry.txt`:

> I keep buying antique maps, and my wife says it's becoming a problem — but I can't help it, I just get drawn in.

[bounty page](https://make.fun/c/u-alfasurya91-the-one-liner-groan-off-5a1febd5)

## Run

```sh
node main.ts
```
